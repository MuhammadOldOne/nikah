# Передача работы: с облачной сессии на ноутбук

Этот файл — точка входа для новой сессии Claude Code на компьютере владельца. Новая сессия начинает с него.

## 1. Где всё лежит

- **Код:** репозиторий `MuhammadOldOne/nikah`, ветка `claude/beautiful-brahmagupta-5xdnk2`. Всё сделанное закоммичено туда.
- **Код старого бота** (только для чтения, приватный): `MuhammadOldOne/nikah-bot`. Его удобно клонировать рядом: `../nikah-bot`.
  - В `nikah-bot/docs/SERVER.md` — данные сервера (IP, пути, имя сервиса). **Их нельзя переносить в публичный репозиторий `nikah`.**
- **Главные документы** (читать в этом порядке):
  1. [`LEGACY_BOT.md`](LEGACY_BOT.md) — решения по связке со старым ботом. Где он расходится с `MVP.md`, прав он.
  2. [`MVP.md`](MVP.md) — продукт: страницы, анкета, отклики, чат, вали.
  3. [`ARCHITECTURE.md`](ARCHITECTURE.md) — устройство кода, контракты сервисов, события, решения (§12).
  4. [`DEPLOY.md`](DEPLOY.md) и [`CUTOVER.md`](CUTOVER.md) — запуск на сервере и переключение со старого бота.
  5. [`REVIEW_PENDING.md`](REVIEW_PENDING.md) — неисправленные замечания проверки (следующая задача).

## 2. Что готово

- Сайт и бот — одна система с общей PostgreSQL. Синхронизация через outbox и `pg_notify`: сообщение из бота видно на сайте сразу, и наоборот.
- Бот повторяет старый @nikah_istina_bot:
  - те же меню, тексты, команды и формат «Анкета №N пишет:»;
  - старые inline-кнопки в переписке пользователей продолжают работать;
  - работает через прокси `TELEGRAM_PROXY`.
- Номера анкет «Анкета №N» вместо имён (адрес `/p/{number}`). Свидетель получает копии всех сообщений и может пометить сообщение, написать в чат или закрыть его.
- Правила общения:
  - контакты в сообщениях скрываются фильтром;
  - антифлуд — 20 сообщений в минуту;
  - у человека только один открытый чат;
  - смотреть анкеты можно только после одобрения своей.
- Перенесённые пользователи сначала дают согласие на обработку данных (152-ФЗ). Неполные анкеты получают предложение «Дополнить анкету».
- `scripts/import_legacy.py --import <data.db> [--commit]` переносит пользователей, анкеты, отклики, чаты и сообщения со старыми номерами и id. Тесты используют синтетическую SQLite-базу.
- Оформление «Никах Истина»: логотип и палитра бота, тёмная тема.
- Запуск в двух режимах: через Caddy или через уже работающий nginx. Отдельные варианты для прокси Telegram на хосте.
- Сквозной тест сайт ↔ бот (`tests/e2e`, запуск с `E2E=1`). Он проверяет свидетеля, фильтр контактов, лимит открытых чатов и вход перенесённого пользователя.

## 4. Локальная разработка на Windows

Проще всего через **WSL2 (Ubuntu)**: сервер тоже Ubuntu, а скрипты написаны на bash. В PowerShell от администратора выполните `wsl --install`, затем работайте внутри Ubuntu.

```bash
git clone https://github.com/MuhammadOldOne/nikah.git && cd nikah
git checkout claude/beautiful-brahmagupta-5xdnk2
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
# PostgreSQL 16 в Docker (Docker Desktop с интеграцией WSL):
docker run -d --name nikah-pg -e POSTGRES_USER=nikah -e POSTGRES_PASSWORD=nikah -e POSTGRES_DB=nikah -p 5432:5432 postgres:16
docker exec nikah-pg psql -U nikah -c "CREATE DATABASE nikah_test OWNER nikah;"
.venv/bin/alembic upgrade head
TEST_DATABASE_URL=postgresql+asyncpg://nikah:nikah@127.0.0.1:5432/nikah_test .venv/bin/pytest -q .
```

- Имя тестовой базы обязательно содержит `test`: тесты удаляют её схему.
- Для e2e нужны Node 22 и Playwright (`npx playwright install chromium`). Подробности — в `tests/e2e/`.

## 5. Запуск на сервере

- **Домен:** `nikah.ascoldone.ru`. DNS: A-запись `nikah` → IP сервера бота.
- **Сервер:** тот же, где работает старый бот (Россия, Ubuntu 24.04, там уже есть nginx). Режим запуска — **nginx** (`DEPLOY.md`), прокси Telegram — по `DEPLOY.md` (проверить `ss -ltnp`).
- **Порядок:**
  1. Поднять базу и сайт **без нового бота**. Старый бот продолжает работать.
  2. Пробный перенос по **копии** `data.db`.
  3. Переключение по `CUTOVER.md`: остановить и отключить старый сервис, снять финальную копию, перенести данные с `--commit`, запустить новый бот с тем же токеном и проверить.
- **Старый бот останавливается только по явной команде владельца.** Его базу не изменять. Перенос читает её только на чтение.

## 6. Правила для любой сессии

- `nikah` — **публичный** репозиторий. В него нельзя коммитить:
  - `.env`, токены, id админов;
  - IP и пути сервера;
  - базы данных и личные данные пользователей.
- Все тексты для пользователей пишутся на русском, код и комментарии — на английском.
- Бизнес-правила живут только в `app/services`, чтобы сайт и бот вели себя одинаково.
- **До запуска — вопросы к юристу:**
  - уведомление Роскомнадзора;
  - текст отдельного согласия (152-ФЗ, особая категория — религиозные убеждения);
  - нужен ли реестр ОРИ;
  - требования 406-ФЗ к авторизации.
